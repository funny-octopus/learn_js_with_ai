## Конспект

Здесь будет накапливаться теория по мере прохождения тем.

### 1.1 Переменные и типы

**8 типов значений:** `string`, `number`, `boolean`, `null`, `undefined`, `bigint`, `symbol` — примитивы, и `object` — всё остальное (массивы, функции, даты — частные случаи объектов).

- `typeof` возвращает строку с типом.
- Историческая особенность: `typeof null === 'object'` (баг, зафиксированный навсегда).
- `typeof function () {}` → `'function'`, хотя функция — объект.
- `typeof []` → `'object'`: массив проверяем через `Array.isArray()`.

**Приведение типов** бывает явным (`Number(x)`, `String(x)`, `Boolean(x)`) и неявным (операторы делают его сами).

- `+` со строкой → конкатенация: `1 + "2"` → `"12"`.
- `-`, `*`, `/` всегда приводят к числу: `"5" - 2` → `3`, `"abc" * 2` → `NaN`.
- `NaN` («not a number») — число, которое не равно само себе: `NaN === NaN` → `false`.
- Объект в строковом контексте → `"[object Object]"`, массив → элементы через запятую: `[] + {}` → `"[object Object]"`.
- `[] == false` → `true`: обе стороны приводятся к `0`.

### 1.2 Область видимости

- `let` и `const` — блочная область видимости, `var` — функциональная (устарел, не используем).
- `const` запрещает переприсваивание, но не делает объект неизменяемым: `const a = []; a.push(1)` — можно.
- Hoisting: объявления поднимаются, но `let`/`const` до строки объявления находятся в «temporal dead zone» — обращение бросает `ReferenceError`. `var` даёт `undefined`.

### 1.3 Равенство, truthy/falsy, `??` и `?.`

- `===` — строгое равенство (тип + значение). **Всегда используем его.**
- `==` приводит типы: `"10" == 10` → `true`, `null == undefined` → `true`, но `null === undefined` → `false`.
- Исключение: `x == null` — короткая и допустимая проверка «null или undefined».
- **Falsy-значения (их ровно 8):** `false`, `0`, `-0`, `0n`, `""`, `null`, `undefined`, `NaN`. Всё остальное truthy — включая `[]`, `{}`, `"0"`, `"false"`, `-1`.
- `??` возвращает правый операнд только если левый `null`/`undefined`. В отличие от `||`, не съедает `0`, `false` и `""`.
- `?.` прерывает цепочку и возвращает `undefined`, если перед ним `null`/`undefined`: `data?.user?.address?.city`.

### 1.4 Функции

- **Объявление функции** поднимается целиком: `hi()` можно вызвать до `function hi() {}`.
- **Функциональное выражение** поднимается только как переменная: `var f = function () {}` до объявления даёт `undefined`, вызов → `TypeError`.
- **Стрелка** (`const f = (x) => x * 2`) — компактная запись, но:
  - нет своего `this` (берёт `this` из окружающего кода);
  - нет `arguments`;
  - нельзя использовать как конструктор (`new`).
- **Параметры по умолчанию** срабатывают только при `undefined`: `greet('')` не подставит «гость».
- Значение по умолчанию вычисляется при **каждом** вызове, поэтому `tags = []` не разделяется между вызовами.
- **Rest `...args`** собирает аргументы в настоящий массив: `sumAll(...nums)`. Старый `arguments` — не массив, лучше не использовать.

### 1.5 Замыкания и `this`

- **Замыкание** — функция помнит переменные из места создания, даже после завершения внешней функции.

```js
function makeCounter() {
  let count = 0;              // живёт в замыкании
  return () => ++count;
}
const next = makeCounter();
next(); // 1
next(); // 2
```

- Каждое замыкание хранит **свою** копию переменных: два `makeCounter()` независимы.
- Классика цикла: `var i` в цикле даёт всем функциям одно и то же `i` (последнее), `let i` — своё значение на каждой итерации.
- **`this` определяется в момент вызова**, а не объявления:
  - `obj.method()` → `this === obj`;
  - простая функция без объекта (строгий режим) → `this === undefined`;
  - `fn.call(other)` / `fn.apply(other, args)` / `fn.bind(other)` — задать `this` вручную;
  - стрелка своего `this` не имеет и `call`/`bind` на неё не действуют.

### 1.6 Массивы

- `map` — новый массив той же длины, преобразует каждый элемент.
- `filter` — новый массив только из подходящих элементов.
- `reduce((acc, item) => …, начальное)` — сворачивает массив в одно значение.
- `find` — первый подходящий элемент или `undefined`; `findIndex` — его индекс или `-1`.
- `some` / `every` — есть хотя бы один / подходят все. На пустом массиве: `some` → `false`, `every` → `true`.
- `sort` **меняет исходный массив** и по умолчанию сравнивает как строки. Поэтому: `[...arr].sort((a, b) => a - b)` — копия плюс числовой компаратор.
- Остальные частые методы: `push/pop` (конец), `shift/unshift` (начало), `splice` (меняют), `slice/concat` (не меняют).
- `for...of` — перебор значений; `forEach` — побочные действия (ничего не возвращает).

### 1.7 Объекты

- **Деструктуризация:** `const { name, age = 18, city: town } = user;` — значение по умолчанию и переименование.
- **Вложенная:** `const { address: { city } = {} } = user;` — защита от отсутствующего `address`.
- **Rest:** `const { password, ...safeUser } = user;` — копия без поля.
- **Spread копирует поверхностно:** `{ ...user, city: 'Сочи' }`. Вложенные объекты остаются общими: `copy.address === user.address`.
- `Object.keys(obj)` / `Object.values(obj)` / `Object.entries(obj)` → массивы ключей / значений / пар `[key, value]`.
- Деструктуризация в параметрах: `function f({ name, age }) { … }`.
- Отсутствующее свойство даёт `undefined`, а не ошибку; ошибка будет только при попытке прочитать свойство у `undefined` (спасает `?.`).
